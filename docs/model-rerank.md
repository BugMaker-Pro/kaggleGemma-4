# 模型进环：一个现成重排器在代码符号检索上能买到什么

问题：论文里所有信号都是词法的——某个词在 issue 里出现过没有。池内 oracle@10 是 0.600，而便宜特征只到 0.361，差的 20 分全在「字面对不上」的符号上（`Colormap.__call__` vs「deprecation warning」）。那 20 分是不是语义的？只能用一个模型来测。

## 仪器

`BAAI/bge-reranker-v2-m3`（568M，XLM-R large，通用领域交叉编码器），**原样使用、不微调**。输入是 `(issue, "path :: qualname\n源码正文")`，对池内 200 个候选逐个打分，取前 10。分母、槽数、池子与其余各臂完全一致。

## 先校准仪器（50 个任务，同一子集）

| 配置 | 模型 r@10 | 同批特征排序 |
| --- | ---: | ---: |
| fp32，512 token，带路径头 | 0.130 | 0.408 |
| fp16，512 token，带路径头 | ~0.19（131 任务上） | 0.445 |
| **fp16，1024 token，带路径头** | **0.247** | 0.408 |
| fp16，2048 token，带路径头 | 0.247（已饱和） | 0.408 |
| fp16，1024 token，**只给正文**（去掉路径与限定名） | **0.069** | 0.408 |

三个结论：

1. **半精度不是问题**（fp32 反而更差），可以排除数值问题。
2. **上下文长度是问题**：512 token 时 issue 被截断，0.19 → 1024 时 0.247，2048 已饱和。所以正式跑用 1024。
3. **路径和限定名是这个模型最强的线索**：把 `path :: qualname` 头去掉，分数从 0.247 掉到 0.069。也就是说，它并不是在「读代码」，而是在**匹配标识符**——和 BM25 做的事高度重合。

## 短名单重排也救不了

把模型限制在特征排序的前 N 个候选里重排（这才是业界的标准用法）：

| 重排范围 | 结果 | 相对特征排序 |
| --- | ---: | ---: |
| 前 10 | 0.445 | ±0（没得排） |
| 前 20 | 0.382 | −6.3 分（p=0.005） |
| 前 30 | 0.355 | −9.1 分（p=0.005） |
| 前 50 | 0.329 | −11.6 分（p=0.001） |
| 前 100 | 0.246 | −20.0 分（p<0.001） |

**越给它自由度，它越差。** 说明它和特征排序不是互补关系，而是更弱的重合关系。

## 全量结果（2,232 个任务）

| 臂 | 符号 r@10 | 文件 r@10 |
| --- | ---: | ---: |
| BM25 | 0.248 | 0.564 |
| 16 特征排序 | **0.361** | 0.643 |
| 交叉编码器**当排序器** | **0.220** | 0.571 |
| 池内 oracle@10 | 0.572 | — |

模型单独：**比 BM25 还低 2.8 分**（p=0.04），比特征排序低 **14.1 分**（CI −0.160,−0.122；228 胜 639 负）。

短名单重排（全量）：

| 重排范围 | 结果 | 相对特征排序 |
| --- | ---: | ---: |
| 前 10 | 0.361 | ±0（没得排） |
| 前 20 | 0.356 | −0.4（p=0.93） |
| 前 30 | 0.331 | −3.0（p=0.002） |
| 前 50 | 0.298 | −6.3（p<0.001） |
| 前 100 | 0.253 | −10.8（p<0.001） |

分桶：quotes −37.8 分、names −33.3、neither −6.3——**它最差的恰好是「issue 引用了源码」那一档**，也就是说它不会做代码到代码的匹配。

## 但它的分数当一个特征，是 +4.1 分

| 配置 | 符号 r@10 | 文件 r@10 |
| --- | ---: | ---: |
| 16 特征 | 0.361 | 0.643 |
| **+ 模型分数（17 特征）** | **0.402** | **0.690** |
| + 历史先验 | 0.381 | 0.671 |
| **+ 模型 + 先验（20 特征）** | **0.423** | **0.712** |
| 去掉图特征、其余全留 | 0.402 | 0.701 |

增益：模型 +4.1 分（CI 0.031–0.052，260 胜 99 负）、先验 +2.1、两者 +6.2。

分桶：quotes +3.1、names +2.6、**neither 0.236 → 0.308（+7.2）**——收益最大的地方是 issue 什么都没说的那 74%。

同一个模型，两种用法差 18 分：**当排序器它是 −14.1，当一个特征它是 +4.1。** 它没学会排序，但学会了在被别人排好的候选里挑出「有点像」的那些。
