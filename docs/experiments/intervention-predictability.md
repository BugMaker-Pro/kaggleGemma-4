## 研究问题

在固定候选池、固定十槽预算下，一次检索干预（真实图一跳提升）的净收益，能否由**干预前可观测、不依赖金标标签或修复结果**的任务级统计量，在**未参与拟合的仓库**上被预测？

这不是把已知结果重新分解一遍。预测变量取自 `data/features_full.jsonl`（检索特征矩阵），被预测量取自 `data/graph_controls.jsonl`（拓扑对照实验的逐任务结果），两者是不同实验、不同文件产生的；拟合在训练仓库上完成并冻结，测试仓库只做一次预测。

## 预测变量（6 个，全部只读 `rows` / `files` / `ids` / `features`）

`rows` 已按 BM25 名次排列（校验过：`bm25_rank` 列为 1.0, 0.5, 0.333, …）。脚本按 `features` 列名取值，不硬编码列下标。

| 变量 | 定义 | 干预前的含义 |
| --- | --- | --- |
| `margin_10_11` | `bm25_score[9] − bm25_score[10]` | 第 10 槽与池内下一个候选的分数间隔，衡量末位槽有多"可挤" |
| `top5_mass` | `Σ bm25_score[:5] / Σ bm25_score[:50]` | 前排分数集中度 |
| `seed_file_spread` | 前 5 候选的 distinct 文件数 | 种子是深挖还是铺开 |
| `seed_degree` | 前 5 候选 `in_degree + out_degree` 的均值 | 种子在图上的连通度 |
| `evidence_top10` | 前 10 候选 `path_in_issue + frame_hit + named_file` 之和 | issue 里明写了多少可直接对上的代码线索 |
| `score_decay` | `bm25_score[0] − bm25_score[9]` | 十分内的分数落差 |

**泄漏防护（脚本内断言）**：构造特征的函数只接收 `rows` / `files` / `features`，不接收整行记录；禁止访问 `labels`、`gold_total`、`gold_files`、`rerank_top10` 及 `graph_controls` 的任何字段。这六个变量在干预发生前、且不看答案纸即可计算。

## 被预测量

对每个 `representation ∈ {metadata, body, dense}`：

```
Δ = arms['real']['symbol'] − arms['base']['symbol']
```

并用 `(arms['real']['gained'] − arms['real']['lost']) / gold_total` 做一致性核对，报告不一致的任务数；不一致时不静默修正，单列披露。`gold_total == 0` 的任务排除。

**主表示预先固定为 `metadata`**（论文的主结果在 metadata 与 dense 上通过校正）；`body`、`dense` 为次要表示，用 Holm 校正三个表示。

## 分折与拟合

- 12 个仓库按名称排序后交替分成两组各 6 个（与仓库既有学习排序器两折完全一致的规则）。两次互换训练/测试，每个任务恰好获得一个 **out-of-fold** 预测。
- 训练折内：六个特征标准化（只用训练折的均值与标准差），岭回归闭式解，**alpha 固定为 1.0**，含截距。不调参、不挑选特征、不看测试折的 Δ。
- 测试折：只用训练折的标准化参数与系数做一次预测。
- 次要分析：单独报告 290 个 Lite 可评分任务的 out-of-fold 表现；Lite 嵌套在全量 split 内，故不作独立重复实验，只作描述。

## 主要指标与不确定性

- **主要指标**：测试折（合并两折的 out-of-fold 预测）上预测值与实测 Δ 的 **Spearman ρ**。选 ρ 而非 Pearson，预先说明因为 Δ 预期高度偏斜且大量为 0。
- **次要指标**：Pearson r；相对"恒判 0"基线的 MSE 改进 `1 − MSE_model / MSE_zero`；非零 Δ 任务数。
- **不确定性**：按仓库 cluster bootstrap，**10,000 次、种子 20261109**，对预先计算的全局平均秩重采样（明确标注这是全局秩近似，不在每个重采样内重新排秩），报告 ρ 的 95% 区间与双侧 bootstrap p。
- **多重比较**：三个表示的双侧 p 做 Holm 校正。主表示 `metadata` 单独判读，校正针对次要表示的整体推断。
