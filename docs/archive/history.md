# 历史决策摘要

旧计划已被当前论文、复现协议和主赛道计划替代。这里只保留研究方向变化及尚未完成的设想；当时的倒计时、候选标题、重复规则和过期待办已移除。

<a id="paper-topic"></a>
## 早期论文选题

最初围绕 SWE-bench Lite 的文件与符号召回差距、候选覆盖和图扩展展开，随后加入全量任务、正文索引和学习排序。早期“图没有收益”“粒度差距不变”的表述已被后续结果收窄，不能作为当前结论。

当前论证以候选覆盖、目标替换损失、真实拓扑信号和具体干预收益的区别为主，见[拓扑结果](../graph-control-results.md)与[新颖性评审](../novelty-review.md)。

<a id="paper-v15"></a>
## v15 排序器扩展计划

这一阶段研究历史频次先验与交叉编码器作为特征的作用，并讨论把 42.3% 作为摘要结果。之后冻结 dense 分数与显式特征的融合达到 44.7%，当前稿件已采用后者；旧版改稿清单不再执行。原模型实验的结果和方法细节保留在[检索与排序记录](../experiments/retrieval.md)。

<a id="research-directions"></a>
## 尚未确证的研究设想

曾提出三个方向：

1. 根据尚未获得代码支持的 issue 证据补充检索，区分查询改写、读取代码反馈、显式证据状态各自的价值。
2. 优先解析可能改变排序决定的图边，先验证可靠边修正是否真的改善下游检索。
3. 联合选择相互补充的代码片段，评估组合是否比单独片段更能支持修复。

查询和反馈先导实验已完成，但未建立稳定的总体收益；多轮证据控制器和互补代码组合选择尚未获得确认性结果。图反事实监督与路由的后续探索也未形成稳定的强基线增益。

相关材料：[查询实验](../experiments/query-generation.md)、[反馈实验](../experiments/feedback.md)、[反事实图算法](../experiments/counterfactual-topology-algorithms.md)。继续研究时应冻结方法并加入新的验证任务，不能在同一基准上反复挑选有利结果。
