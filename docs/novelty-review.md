# 新颖性复核与下一步实验（2026-11-01）

## 后续状态：实验已完成

2026-11-01 已按下述方向完成全部 2,232 个任务的固定候选池实验。真实图相对主随机对照在 metadata/dense 下有正收益，但表示交互未通过 Holm 校正；这不支持“强文本让图无用”的预设故事。完整结果见 [graph-control-results.md](graph-control-results.md)，研究判断与审计差异见 [graph-control-interpretation.md](novelty-review.md#graph-control-interpretation)。以下“下一步”章节保留为实验前的设计记录，不代表尚未执行。

## 判断

当前成果是一篇有较强审计基础的实证诊断与资源论文。**仅靠“文件命中不等于符号命中”不足以支撑强新颖性；图/embedding 消融也不是新贡献。** 改写能使贡献诚实且可辨识，但不会把已有实验变成新算法。整体能否获奖取决于评审与其他投稿，不能从本仓库推断。

当前可以主张：在一个明确的静态检索设置中，联合报告候选覆盖、固定槽位下的命中增减、索引内容干预、规模扩展与独立金标审计。不要主张首次符号评测、首次图消融、图无用、通用样本量定律或已改善修复率。

## 已做的修正

1. 标题改为 *Beyond File Hits: Candidate Coverage and Graph Utility in Code Localization*；贡献落到实验诊断，不再宣称“issue 有信号、图没有”。
2. 明确 Lite 无统计显著改善不等于零效应；全量图重排 +2.2 点、图特征 +2.7 点均保留。
3. 区分固定十槽、字符数量、原始候选池和扩展后的可访问候选集。
4. 说明 Lite 包含于全量；训练量和测试样本构成同时变化，不能仅据此断言手写规则失效的原因。
5. 补全两折按仓库评估、dense 输入差异、模型与截断配置，并将全量五个主要排名列为一张表。
6. 将有限总体不放回子采样称为条件检出频率，解释满样本列为什么必然是 0/1。
7. 将 16× 表述限定为源代码长度比例；不等同于 agent token、耗时或修复收益。
8. 将 11.9% 标记为可达金标 macro recall，而不是不扣重叠与替换损失的净收益承诺。

## 优先补强的科学问题

**图的增益到底来自真实关系，还是来自检索底座欠缺正文与文件内候选分配？**

这比“再做几个图算法”更有区分度。当前结果不能回答：图的八臂消融在 metadata-only BM25 上进行，body/dense 增强实验没有构成完整交叉设计；+2.2 点也未排除“同文件重排”解释。

建议分两阶段，先做便宜且能推翻主张的实验。以下是看到现有结果之后提出的后续方案，**不是原实验预注册，也尚无结果**。

### A. 真图与位置对照（第一优先级）

在同一候选池、同一种子规则、同样十槽预算上比较：

- 原始文本排序；
- 真实图邻近重排；
- 只使用同文件关系的重排；
- 匹配度数及文件内/跨文件边比例的重连图重排，多个预先固定随机种子。

仅随机打乱所有边会改变图的度数和文件结构，不足以隔离拓扑信息。记录重连是否成功、实际保持了哪些性质，无法匹配的仓库单列。分开报告池内排序与池外扩展，不能让更大候选集伪装成更好排序。

主要对比是真实图减匹配对照的符号 recall@10；同时报告 gained/lost gold、文件 recall、运行时间和按仓库区间。只有真实图稳定优于文件与重连对照，才支持“拓扑本身有独立贡献”。否则结论应收窄为文件内候选分配或其他相关结构信号。

### B. 图 × 检索表示的交互（第二优先级）

将 A 中的对比重复在 metadata BM25、body-inclusive BM25、dense/混合排序上。先用共同候选集隔离排序交互；另做自由候选生成比较，回答覆盖问题。不得混为同一个消融。

预先固定主要交互：

`(真实图 − 对照 | 强检索) − (真实图 − 对照 | metadata BM25)`

如果图增益随表示增强明显缩小，可支持“部分图收益是检索表示缺失的补偿”；若仍稳定存在，则支持二者互补。两种结果都可以写，不能把期望的负交互当成已证实结论。需要事先列出主要比较、随机种子、候选池、符号/文件定义，控制多重比较，并保留失败与无效结果。

### C. 预算与下游验证

固定 token 预算是当前效度缺口，应补一个主要预算与敏感性范围；使用同一 tokenizer 和相同呈现文本。随后如计算资源允许，在固定模型/提示词/修复预算下做检索结果的下游对照，报告 resolved rate 及成本。不要只挑检索已获益的任务运行 agent，这会产生选择偏差。

这些实验能提高论证辨识度，但不能承诺足够新或一定获奖。仅扩大任务数、换一个 LightGBM 超参或再写一遍“file ≠ symbol”，不能实质解决新颖性问题。

## 拓扑对照完成后的研究判断（2026-11-01）

这组实验增加了论文的实证辨识度，但**没有证实“增强文本后图就没有价值”**，也没有创造新算法。更稳的贡献是区分 **结构信号是否存在** 与 **使用结构的重排规则是否有净收益**。

## 做完了什么

全部 2,232 个任务，固定原始候选池和五个保留种子；三种排序表示（metadata、正文 BM25、冻结 dense），真实图、同文件控制、两种约束随机图。每个随机图族五个固定种子、每边 20 次交换尝试。五项主要比较和 Holm 校正在新结果检查前确定。单轮静态检索，非 agent 修复实验。

所有任务复现历史全量 metadata 图排序。独立审计完成 734,354 项检查、零失败；12 个仓库各重放一项随机对照。新增测试覆盖图约束、缓存等价、BM25 全语料统计、仓库符号翻转、Holm 校正与种子改善空间。

## 结果如何改变主张

| 结论 | 证据 | 可以说到哪里 |
| --- | --- | --- |
| 真实拓扑优于保持粗粒度结构的随机图 | metadata +2.14 点、dense +1.76 点；Holm p=0.0137/0.0049 | 在本候选池、图构建器和排序规则下，有超出每节点文件内/跨文件度数的信息 |
| 正文底座上的真实图优势证据较弱 | +0.90 点；Holm p=0.1787 | 不能宣称显著，也不能宣称等价或无效 |
| 有信号不等于净收益 | 真实图相对原排序：metadata +2.19、正文 −0.01、dense +0.64 点 | 拓扑检验与策略收益需要分开汇报；dense 净收益的次要仓库检验 p=0.069 |
| 更强表示削弱图优势尚未确立 | 正文交互 −1.24 点，Holm p=0.126；dense 交互 −0.38 点，p=0.598 | 不能写成“文本解释掉了图”或“图只是在补弱基线” |
| 控制得更严格，剩余差距变小 | file-pair null 下 metadata/dense 残差约 +0.86/+0.65 点 | 属次要分析，且严格 null 平均仅替换 19.0% 边，不是机制分解或方差解释比例 |
| 文件关系不能简单替代真实图 | 真实图相对同文件控制的仓库检验不显著，方向依表示变化 | 同文件控制密度不同，不能据此证明拓扑冗余；其文件召回明显下降也需披露 |

主随机对照平均替换 54.2% 原始边，只有 28 个任务完全不能交换；不是所有 null 都僵住。严格对照有 273 个任务不能交换、345 个最终边集没变，结论必须保留这一限制。不要把“54.2% 边被替换”写成“图已经均匀随机化”或“交换链充分混合”。

## 审计发现并披露的两个细节

1. **Lite 与全量历史协议不同。** 原 Lite 图重排可以移动前五个种子；全量实现保留它们。这次统一采用全量规则。共同候选池上的 Lite 子集 metadata 图 recall 是 0.3044，不能与旧 Lite 0.287 当作同协议重复实验。论文方法和限制已说明，但原 Table 2 和新 Table 8必须分别读。
2. **dense 并列规则。** 本次按冻结协议保留保存的 encoder 顺序；历史融合脚本按四舍五入分数重新排序，以候选索引打破并列。18 个任务的前十成员、19 个任务的种子成员不同，只有一个任务的 dense 基线 recall 改变，因此全量基线为 0.3659 而旧值为 0.3661。事后采用历史规则完整重算控制，五项主要推断未改变。结果保留在 `data/graph_controls_tie_sensitivity.json`，主实验未替换。

## 对新颖性的判断

比“file 不等于 symbol”更强的点是：**用约束拓扑反事实对照，把结构信号、候选集合与具体使用策略的净收益分开测量**。正文与 dense 排序并没有一致地消除结构信号，但简单邻接促进规则也没有稳定改善它们。这是一项带控制和限制的实证发现。

还不能主张首次做图对照、首次发现表示与拓扑交互、证明图普遍不必要，或者优于已有 agent。对 Bellam、LocAgent、ARISE 等工作的完整比较仍重要；这组结果加强了本稿自己的证据，不构成穷尽文献后的首创证明。

后续若继续投入，优先考察如何选择图干预、固定 token 预算和下游验证，而不是反复换随机种子找显著性。设计干预选择器时，需要新的开发/评估隔离或外部验证，不能在当前 2,232 任务上反复挑规则后声称未见测试。
